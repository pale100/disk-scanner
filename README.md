# disk-scanner
Gelişmiş disk tarama sistemi ile aradığınız dosyaları anında bulun. Telegram: palesoftware

Kurulum :
pip install Flask

Kullanım :
python app.py

daha sonra tarayıcıda http://127.0.0.1:57890/ bunu açın.

Windows expolerer'in hantal arama sistemi ve arama çubuğunda sadece windowsun kurulu olduğu dizinde arama yapması vesilesi ile kendim için bir script geliştirdim bunu ücretsiz olarak githubda paylaştım ihtiyacı olanlar faydalanabilir, geliştirmeler ekleyebilir.

Temel amacı aradığınız dosyayı ultra hızlı şekilde tüm disklerde aramak ve sonuçları karşınıza çıkarmak

Milyonlarca dosyayı 20 saniyede tarayabilicek hızdadır (PC'den pc ye değişebilir.)
